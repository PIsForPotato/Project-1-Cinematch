# Cinematch

Cinematch is a movie managing program. It allows users to track the movies they've watched and search through movies they have not. It includes searching by genre and title. 

## Installation and Setup
The device or platform that you are running Cinematch on must be able to run Java. After Java is set up, you can run the following command in terminal to clone this repository. 

```
git clone https://github.com/PIsForPotato/Project-1-Cinematch
```

This should include the cinematch package setup to run.

### Zip file alternative
A zip file of the project is included in this repository. 

For the case of Eclipse (the IDE where this project was built), one can import this project via "File" -> "Import..." -> "Existing Projects into Workspace" and selecting a downloaded Cinematch.zip.
